# Enterprise Multi-Branch WAN Infrastructure using GNS3

## 📌 Project Overview

This project demonstrates the design and implementation of a **Multi-Branch Enterprise WAN Infrastructure** using **GNS3**. The network connects the Headquarters with five branches: **Lahore, Karachi, Islamabad, Peshawar, and Multan**.

The project focuses on reliable WAN connectivity, VLAN segmentation, IP addressing, OSPF dynamic routing, network redundancy, and troubleshooting.

## 🔄 Routing

**OSPF** is used as the dynamic routing protocol to provide automatic route exchange and efficient communication between different branches.

---

## 🔁 Redundancy

Primary and backup routers are configured at the branches, while the WAN Core uses multiple paths to improve **network availability and reliability**.
